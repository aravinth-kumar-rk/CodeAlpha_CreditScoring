# CodeAlpha Credit Scoring Model (Task 1)

An automated machine learning pipeline built to assess creditworthiness and predict loan default risks with **99.00% accuracy**. Developed as part of the CodeAlpha Machine Learning Internship.

## 🚀 Project Overview
This project simulates a real-world financial risk assessment engine. It evaluates an applicant's financial background (income, existing debts, and payment history) to determine whether they qualify for credit or pose a high default risk.

* **Target Accuracy:** 99.00%
* **Algorithm Used:** Decision Tree Classifier (`DecisionTreeClassifier`)
* **Environment:** Google Colab / Python
